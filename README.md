# Trading Journal - Android APK (GitHub se automatic)

1. github.com par naya repository banao (e.g. `trading-journal`).
2. Is folder ki saari files (hidden `.github` folder ke saath) us repo me upload/push karo.
3. Repo ke **Actions** tab me "Build Android APK" apne aap chalega (5-8 min).
4. Complete hone par repo ke **Releases** (right side) se `app-debug.apk` phone me download karo aur install karo
   (Settings me "Install unknown apps" allow karna padega).

Aage app me badlaav karoge (`www/index.html`) aur push karoge, to nayi APK apne aap ban jayegi.
Data phone me hi save hota hai. Backup/Restore Journal tab me hai.
